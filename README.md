# Intranet-Corporativa
Interface de intranet corporativa desenvolvida com foco em experiência do usuário, centralização de sistemas, comunicação interna e visualização de informações.  Tecnologias: HTML5, CSS3, JavaScript, jQuery e Tailwind CSS.  Recursos: Dashboard, menu hierárquico, central de aplicativos, notícias, campanhas, carrossel, modais e layout responsivo.
